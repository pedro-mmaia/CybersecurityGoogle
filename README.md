# Google Cybersecurity Professional Certificate 🛡️

Este é o meu repositório para o curso [Google Cybersecurity Professional Certificate](https://grow.google/certificates/cybersecurity/). Criei este espaço para armazenar, organizar e documentar todas as atividades, projetos práticos e laboratórios que realizei ao longo da minha formação.

Durante o curso, aprendi desde os fundamentos essenciais de segurança da informação até habilidades mais avançadas, como proteção de redes, mitigação de ameaças, gestão de acessos no Linux, análise de vulnerabilidades e a automação de tarefas usando Python e SQL.

---

## 📂 Meus Projetos e Atividades

Abaixo deixei um resumo de cada um dos laboratórios e módulos que desenvolvi. Você pode clicar no título de cada atividade para acessar os arquivos detalhados:

### 1. 🔍 [Analyze Network Attacks](./analyze-network-attacks/)
**Resumo:** Neste exercício, foquei na investigação de incidentes de rede. A atividade envolveu a análise detalhada de tráfego e logs para identificar padrões de ataques cibernéticos, compreendendo vetores de ataque e registrando evidências essenciais.

### 2. 🐍 [Automate Cybersecurity Tasks with Python](./automate-cybersecurity-tasks-with-python/)
**Resumo:** Aqui, demonstro o uso da linguagem Python para automatizar tarefas comuns nas operações de segurança. Criei scripts para manipulação e atualização automática de listas de controle de acesso (allow lists), garantindo mais agilidade nesse processo.

### 3. 🐧 [File Permissions in Linux](./file-permissions-linux/)
**Resumo:** Neste laboratório de segurança de Sistemas Operacionais, abordei a auditoria e configuração de permissões de arquivos e diretórios no Linux. Apliquei comandos práticos e o **princípio do menor privilégio** para garantir a proteção de recursos do sistema.

### 4. 🌐 [Network Layer Analysis](./network-layer-analysis/)
**Resumo:** Fiz uma análise aprofundada da infraestrutura de redes (TCP/IP e Modelo OSI). A atividade consistiu em investigar incidentes baseados em tráfego de rede, explorando como os dados são encapsulados, roteados e onde falhas ou interceptações podem ocorrer.

### 5. ⚠️ [Vulnerability Assessment](./vulnerability-assessment/)
**Resumo:** Laboratório prático sobre avaliações estruturadas de vulnerabilidade (Vulnerability Assessment). Meu foco aqui foi mapear ameaças, calcular o risco de exposição utilizando o sistema CVSS e propor estratégias claras e acionáveis de mitigação, documentando tudo em relatórios de auditoria.
