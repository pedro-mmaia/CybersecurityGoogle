# Google Cybersecurity Professional Certificate 🛡️

Bem-vindo ao repositório **CybersecurityGoogle**! Este espaço foi criado para armazenar, organizar e documentar todas as atividades, projetos práticos e laboratórios realizados durante a formação [Google Cybersecurity Professional Certificate](https://grow.google/certificates/cybersecurity/).

O curso abrange desde os fundamentos essenciais de segurança da informação até habilidades avançadas de proteção de redes, mitigação de ameaças, gestão de acessos no Linux, análise de vulnerabilidades e a automação de tarefas usando Python e SQL.

---

## 📂 Projetos e Atividades

Abaixo está o resumo de cada um dos módulos e laboratórios desenvolvidos ao longo do curso. Clique no título da atividade para acessar os arquivos detalhados:

### 1. 🔍 [Analyze Network Attacks](./analyze-network-attacks/)
**Resumo:** Exercício focado na investigação de incidentes de rede. A atividade envolve a análise detalhada de tráfego e logs para identificar padrões de ataques cibernéticos, compreendendo vetores de ataque e registrando evidências essenciais.

### 2. 🐍 [Automate Cybersecurity Tasks with Python](./automate-cybersecurity-tasks-with-python/)
**Resumo:** Demonstração do uso da linguagem Python para automatizar tarefas comuns de operações de segurança. Inclui scripts para manipulação e atualização automática de listas de controle de acesso (allow lists), garantindo agilidade no processo.

### 3. 🐧 [File Permissions in Linux](./file-permissions-linux/)
**Resumo:** Focado em segurança de Sistemas Operacionais. O laboratório aborda a auditoria e configuração de permissões de arquivos e diretórios no Linux, aplicando comandos vitais e o **princípio do menor privilégio** para proteção de recursos.

### 4. 🌐 [Network Layer Analysis](./network-layer-analysis/)
**Resumo:** Análise aprofundada da infraestrutura de redes (TCP/IP e Modelo OSI). A atividade investiga incidentes baseados em tráfego de rede, explorando como os dados são encapsulados, roteados e como interceptações ou falhas podem ocorrer.

### 5. ⚠️ [Vulnerability Assessment](./vulnerability-assessment/)
**Resumo:** Laboratório prático sobre avaliações estruturadas de vulnerabilidade (Vulnerability Assessment). O foco é mapear ameaças, calcular o risco de exposição utilizando o sistema CVSS e propor estratégias claras e acionáveis de mitigação através de relatórios de auditoria.

*   **Sistemas Operacionais e Linha de Comando:** Linux, Bash

*   **Segurança e Governança:** NIST CSF, Tríade CIA, Gestão de Identidade e Acesso (IAM), SIEM, Resposta a Incidentes, CVSS
