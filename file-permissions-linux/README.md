# File Permissions in Linux

Este diretório contém relatórios e estudos de caso sobre a gestão de permissões de arquivos e diretórios no sistema operacional Linux, o que representa um pilar fundamental da segurança de sistemas.

## Estrutura do Diretório

- **`reports/`**: Pasta contendo relatórios detalhados sobre auditoria e configuração de permissões de acesso.
  - `FilePermissions.pdf`: Documento com o relatório completo detalhando uma análise prática de permissões de arquivos.

## Objetivo

Demonstrar conhecimento sobre o sistema de permissões do Linux (comandos como `chmod`, `chown`, e o entendimento de leitura/escrita/execução para usuário, grupo e outros) e ilustrar a aplicação do princípio do menor privilégio para garantir a segurança e a integridade de dados corporativos.
